# Privacy Policy: Markdown Beautifier

Last updated: October 29, 2026

- The extension does not collect, store, or share personal data.
- It sends no data over the network.
- It reads only the Markdown file open in your browser, and only to display it.
- It has no analytics, no advertising, and no user accounts.
- It asks for no browser permissions. It runs only on pages whose address ends in `.md` or `.markdown`.
